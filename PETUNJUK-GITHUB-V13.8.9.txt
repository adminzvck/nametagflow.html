NAMETAGFLOW V13.8.9 — PEMBARUAN TERBARU

1. Ekstrak ZIP ini, upload SEMUA ISI ke folder index.html lama di GitHub.
2. Commit, tunggu GitHub Pages selesai, lalu Ctrl+Shift+R di aplikasi.
3. Pastikan sidebar V13.8.9.
4. Di halaman utama klik Cetak Produksi > Kelola font.
5. Klik Deteksi font yang terpasang dan Izinkan bila diminta. Jika font
   tersedia, status Arial Regular dan Swis721 BT Regular menjadi siap.
6. Buat lembar cetak BARU dari pesanan. Di atas gambar kertas lihat
   Font pada lembar ini. Nama tanpa NIP harus menampilkan Arial Regular
   (lokal asli); model dengan NIP memakai Swis721 BT Regular (lokal asli).
7. Jika yang dibuka adalah riwayat lama, font arsip tetap seperti versi
   pembuatannya. Buat lembar baru untuk menggunakan font asli terbaru.
8. Kelola font juga ada di bagian atas pratinjau, di samping Riwayat.
   Menu ini menghubungkan/mengganti file Arial dan Swis721 yang sesuai;
   bukan memilih font sembarang. Tombol Kembali membawa ke layar sebelumnya.

tetap ada; font asli tetap dibaca dari PC dan tidak termasuk ZIP/GitHub.
