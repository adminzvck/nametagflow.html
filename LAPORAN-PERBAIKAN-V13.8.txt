CATATAN FONT
Arimo Regular digunakan sebagai pasangan metric-compatible Arial. Untuk desain dengan NIP digunakan Nimbus Sans Regular yang dikalibrasi horizontal 0,80 terhadap metrik Swis721 BT pada SVG referensi. Keduanya dikonversi menjadi path/kurva. Bentuk glyph sangat dekat tetapi tidak diklaim identik node-per-node dengan font proprietary Arial/Swis721 BT. File font proprietary tidak disertakan.

PROMPT GEMINI
Prompt file dan tombol “Salin prompt Gemini” sudah memakai aturan yang sama: sumber nama terbaru menang, lowercase semua -> uppercase kecuali dilarang, format nama yang sudah sesuai tidak diubah, dan nama saja default Model 1.
