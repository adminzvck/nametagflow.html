NAMETAGFLOW V13.8.10 — ARIAL BOLD 28 PT

1. Simpan Backup & draf dari aplikasi lama, lalu ekstrak ZIP ini.
2. Upload SEMUA ISI folder hasil ekstrak ke folder index.html lama di GitHub.
   Upload isi folder, bukan file ZIP. Pertahankan vendor, licenses, tests,
   dan backend. File lama lain di GitHub tidak perlu dihapus.
3. Commit changes. Tunggu GitHub Pages selesai, lalu tekan Ctrl+Shift+R.
   Pastikan sidebar menunjukkan V13.8.10.
4. Buka Cetak Produksi > Kelola font > Deteksi font yang terpasang.
   Izinkan akses font jika diminta. Pastikan Arial Bold siap.
5. Jika perlu memilih manual: pada kolom Arial Bold, klik Pilih file.
   Masukkan C:\Windows\Fonts\arialbd.ttf pada kolom Nama file > Buka.
   Swis721 BT tetap Regular/Roman. Yang sudah tersimpan tidak perlu dipilih ulang.
6. Buat lembar cetak BARU dari pesanan. Panel Font pada lembar ini harus
   menampilkan Arial Bold (lokal asli) · 28 pt untuk nama tanpa NIP.
7. Cetak PDF dengan Actual size / 100%.

Nama tanpa NIP sekarang Arial Bold tepat 28 pt. Nama dengan NIP dan baris NIP
mempertahankan Swis721 BT Regular. Batas 7,3 cm tanpa logo / 5,5 cm dengan logo
hanya mengecilkan lebar tulisan yang melebihi batas. Nama lebih pendek tidak
DIPERBESAR agar memenuhi batas. Spasi nama pendek yang sudah ada tetap berlaku.

Riwayat lama tidak otomatis berubah Bold. Buat lembar BARU untuk hasil baru.
Arial Regular yang tersimpan dipertahankan untuk riwayat v13.8.6–v13.8.9.

Apps Script tidak perlu diubah untuk pembaruan font ini.
Semua file paket v13.8.9 tetap disertakan. Font asli tidak termasuk ZIP,
tidak diunggah ke GitHub, dan dibaca dari PC melalui menu Kelola font.
Rincian: PETUNJUK.txt. Contoh PDF/PNG/SVG lama adalah arsip, bukan contoh Bold baru.
